# Who gets to be an American Girl? 

### by Julia Sienkiewicz
### Lede Program Summer 2026

Who gets to be an American Girl? This project explores the promise (and limits) of representation through American Girl Dolls. 

Artifacts of my previous analysis can be found in the "roads-not-taken" folder. 

The original dataset on the dolls and their features was found courtesy of collector and fan <a href="https://evelynroseag.wordpress.com/2024/06/21/ultimate-inventory-spreadsheet/">Evelyn Rose AG</a> who crafted a Google Sheets doc for other collectors to keep track of their own collections by all kinds of attributes: face molds, hair color, eye color, etc. The collector dashboard she built is pretty darn neat. 

The data were then cleaned in R and converted to CSV. The original iteration of this project was a static "catalog" charting the evolution of the AG brand as part of my masters' capstone at <a href="https://www.mica.edu/mps-data-visualization-and-communication/" style='color:#e10098;'>MICA</a>
